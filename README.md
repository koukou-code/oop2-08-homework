# 第8回個人課題：じゃんけんアプリ＆占いアプリ

## 1. 動作確認方法
1. プロジェクトディレクトリで以下を実行してサーバーを起動します。
   ```bash
   $ pyenv local 3.14.4
   $ python main.py
   ```
2. ブラウザで `http://localhost:8888/` にアクセスします。
   - じゃんけんアプリ: `http://localhost:8888/janken`
   - 占いアプリ: `http://localhost:8888/uranai`

## 3. デザイン・実装で工夫したポイント
- 占いのメッセージは、少し厳しめで小悪魔っぽい口調にして個性を出した
- 課題1・課題2を機能ごとに5つのブランチに分け、それぞれPull Requestを作成してからmainにマージした
  - 課題1：接待モード（#1）、勝利時の赤文字表示（#2）
  - 課題2：入力画面とルーティング（#3）、計算ロジックと入力不備の判定（#4）、CSS（#5）
- コミットやPull Requestには、変更内容と動作確認の結果を書いて、何をしたか後から追えるようにした
- 画面の装飾はシンプルにし（中央寄せと結果の色のみ）、Webアプリの仕組みとGitの手順を優先した
